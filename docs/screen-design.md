## 4. 画面遷移

### 4.1 管理画面の基本遷移
- `/login`
  - ログイン成功 → `/app/bot`

- `/app/bot`
  - FAQ管理へ → `/app/faqs`
  - 文書管理へ → `/app/documents`
  - デザイン設定へ → `/app/design`
  - 問い合わせ設定へ → `/app/contact`
  - テストチャットへ → `/app/test-chat`
  - 会話ログへ → `/app/conversations`

- `/app/faqs`
  - 新規作成 → `/app/faqs/new`
  - 編集 → `/app/faqs/:faqId/edit`
  - 保存後 → `/app/faqs`

- `/app/documents`
  - アップロードへ → `/app/documents/upload`
  - 完了後 → `/app/documents`

### 4.2 公開画面遷移
- `/c/:slug`
  - 有効slug → 公開チャット画面
  - 無効slug → 404案内
  - 非公開 → 非公開案内

### 4.3 LP導線
- `/`
  - ログイン → `/login`
  - 将来的な問い合わせ導線 → 外部フォームまたはメールリンク

## 6. MVP時点のUI設計方針
- 1ユーザー1ボット前提のため、ダッシュボードは置かない
- ログイン後はボット設定画面を初期画面とする
- 主要導線はサイドバーでシンプルに整理する
- 公開チャットはスマホファーストで設計する
- 管理画面も最低限スマホ対応する
