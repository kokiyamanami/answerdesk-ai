# AnswerDesk AI 無料プランPRD

## 1. 概要
AnswerDesk AI は、ユーザーが自分専用のFAQチャットボットを管理画面から作成・公開できるSaaSである。  
登録したFAQやPDFをもとに、RAGを利用したチャット応答を提供する。  
公開チャット画面はURLで一般公開でき、エンドユーザーは匿名で利用できる。

本サービスは幅広い用途を想定する。

- 中小企業の問い合わせ窓口
- ECサイト運営者
- 社内FAQ
- 地方公共団体の案内窓口

AnswerDesk AI は、まず無料プランで十分価値を体験できることを重視する。

---

## 2. 目的
ユーザーが、専門知識なしで以下を実現できるようにする。

- FAQチャットボットを作成する
- FAQやPDFを学習データとして登録する
- 公開チャット画面を簡単に設定する
- 回答できない場合は問い合わせへ誘導する
- スマホでも使いやすい公開チャットを運用する

---

## 3. 対象ユーザー

### 3.1 一次ユーザー（管理者）
- 中小企業の問い合わせ窓口担当
- ECサイト運営者
- 社内FAQ管理者
- 地方公共団体の案内担当

### 3.2 二次ユーザー（公開チャット利用者）
- 企業サイト訪問者
- EC利用者
- 社内メンバー
- 住民・利用者

---

## 4. プロダクト前提
- 1ユーザー = 1ボット
- 管理者のみ認証
- 公開チャットは匿名利用
- 回答は登録済みソースの内容のみ
- LLMの一般知識で補完しない
- 十分な根拠がない場合は回答せず、問い合わせ導線を出す
- 無料プランでは、チャット画面のデザインはプリセットテーマ選択方式
- 各ボットは公開チャットURL用の一意な `slug` を持つ
- 公開チャットURLは `https://answerdesk.ai/c/{slug}` 形式とする
- `slug` は自動生成され、管理者が編集可能である
- `slug` はURLとして安全な文字のみ使用可能とする

---

## 5. 無料プラン要件
無料プランは、ユーザーが最短で1つのFAQチャットボットを作って公開できることを目的とする。

### 5.1 無料プランで提供する価値
- 1ユーザー1ボットを作成できる
- FAQやPDFをもとにチャットボットを構築できる
- 管理画面から公開チャットの見た目を最低限設定できる
- URLですぐに公開できる
- 回答できない質問は問い合わせへ自然に誘導できる

### 5.2 無料プランの機能
- 管理者ログイン
- ボット作成・管理
- FAQ手入力
- PDFアップロード
- 公開URL発行
- 匿名公開チャット
- タイトル設定
- アイコン設定
- 初期メッセージ設定
- プリセットテーマ選択
- 未ヒット時問い合わせ導線設定
- テストチャット
- レスポンシブ対応
- LP表示

### 5.3 無料プランのデザイン設定
管理画面から以下を設定できる。

- チャットタイトル
- チャットアイコン
- 初期メッセージ
- プリセットテーマ

#### プリセットテーマ
無料プランでは色の個別編集は不可とし、以下のようなプリセットテーマから選択する。

- Blue
- Green
- Purple
- Orange
- Neutral

テーマは少なくとも以下のUIに反映される。
- 背景
- ボタン
- 吹き出し
- 文字色
- アクセントカラー

### 5.4 無料プランの問い合わせ導線
未ヒット時には、管理画面で設定した問い合わせ導線を表示する。

設定可能項目:
- 未ヒット時メッセージ
- 問い合わせURL
- 問い合わせメールリンク

## 6. 機能要件

### 6.1 認証
- 管理画面は認証必須
- 管理者のみログイン可能
- 公開チャット画面は匿名アクセス可能

### 6.2 ボット管理
- 1ユーザーにつき1ボットを持つ
- ボットを作成できる
- ボット設定を更新できる
- 公開/非公開を切り替えできる
- 公開URL用の `slug` を設定できる
- `slug` は全ボットで一意であること

### 6.3 学習データ管理
- FAQを手入力で追加/編集/削除できる
- PDFをアップロードできる
- PDFの処理状態を確認できる

### 6.4 公開チャット画面デザイン設定
- タイトルを設定できる
- アイコンをアップロードできる
- 初期メッセージを設定できる
- 無料プランではプリセットテーマを選択できる
- 管理画面でプレビュー表示できる

### 6.5 RAG回答
- ユーザー質問に対して関連文書を検索する
- 検索結果をもとにLLMが回答を生成する
- 回答は登録済みソースの内容に限定する
- LLMの一般知識で補完しない
- 根拠が不足する場合は回答しない

### 6.6 未ヒット時の問い合わせ誘導
- 未ヒット判定時に固定案内文を表示する
- 問い合わせ先URLを表示できる
- メールリンクを表示できる
- これらは管理画面から設定できる

### 6.7 公開URL / slug 管理
- ボットは公開URL用の `slug` を持つ
- `slug` はボット作成時に、ボット名またはチャットタイトルを元に自動生成する
- 管理者は管理画面から `slug` を編集できる
- 公開URLは `https://answerdesk.ai/c/{slug}` 形式で生成される
- 管理画面上で公開URLを表示し、コピーできること
- 公開後に `slug` を変更した場合、公開URLが変わることを警告表示すること

#### slug の入力制約
- 使用可能文字は以下とする
  - 半角小文字英字 `a-z`
  - 数字 `0-9`
  - ハイフン `-`
- 3文字以上50文字以下とする
- 先頭および末尾にハイフンは使用不可とする
- 日本語、空白、記号は不可とする

### 6.8 公開チャット画面
- URLで公開できる
- 匿名利用できる
- タイトル、アイコン、初期メッセージを表示する
- 選択したプリセットテーマを反映する
- 回答をチャット形式で表示する
- スマホ/PCで崩れないレスポンシブUIにする
- `slug` が存在しない場合は404画面を表示する
- `slug` が存在してもボットが非公開の場合は非公開案内画面を表示する

### 6.9 テストチャット
- 管理者が公開前に応答確認できる
- 未ヒット時の問い合わせ導線も確認できる
- テーマ反映を確認できる

### 6.10 LP
- サービス概要を紹介するLPを提供する
- プランを表示する
  - 無料
  - 有料（Coming Soon）
  - カスタマイズ（Coming Soon）
- 問い合わせ導線を設置する

## 7. AI / RAG 要件

### 7.1 対象ソース
無料プランで扱う対象:
- FAQ手入力
- PDF

### 7.2 回答ポリシー
- 回答はソースに根拠がある内容のみ
- ソースにない情報は回答しない
- 推測で補完しない
- 不明な場合は問い合わせへ誘導する

### 7.3 未ヒット判定
以下のいずれか、または組み合わせで判定する。
- 類似検索スコアが閾値未満
- 上位候補の根拠が不十分
- LLMが根拠不足と判断

### 7.4 出力形式
- 通常時: 回答 + 参照ソース
- 未ヒット時: 固定メッセージ + 問い合わせ導線

## 9. 非機能要件

### 9.1 レスポンシブ対応
- 公開チャット画面はスマホファーストで設計する
- 管理画面もスマホで最低限操作可能とする

### 9.2 セキュリティ
- 公開されていないボットへ匿名アクセスできないこと
- アップロードファイルの基本バリデーションを行うこと
- 管理画面APIは認証必須であること

### 9.3 パフォーマンス
- 通常の質問応答は実用的な待ち時間内で返すこと
- PDF取り込みは非同期で処理可能であること

### 9.4 可観測性
- チャット失敗を記録できること
- PDF取り込み失敗を確認できること
- 未ヒット発生を追跡できること

## 12. 技術前提
- フロントエンド: React
- バックエンド: Python
- API: FastAPI想定
- DB: PostgreSQL
- ベクトル検索: pgvector想定
- ファイル保存: S3互換ストレージ

## 13. リスク
- PDFの品質によって回答精度が不安定になる
- 未ヒット判定が甘いと誤回答が発生する
- 幅広い業種向けのため、文言設計が抽象的になりやすい
- 無料プランの制約が強すぎると価値が伝わりにくい可能性がある
